# Crash Forge: Racing Launcher v0.3.39 — Forge Hub Mod Manager

![Forge Hub Mod Manager](https://github.com/CarisaDemon/Crash-Forge-Launcher/releases/download/v0.3.39/forge-news-v0.3.39.webp)

- **Mod Manager:** Browse online mods and installed mods, search and filter by category; Installed Only and Hide Local.
- **Separate mod folders:** Each verified ZIP uses a permanent web ID in \`assets/mods/<web-id>/\`, with independent native INI metadata and Enable/Disable.
- **Modpacks:** Each component installs to its own folder, with safe backups and rollback. Existing local mods are not migrated or removed.
- **Standalone Windows editors:** Model Importer, CSEQ/MIDI and OGG Toolkit EXEs are included in the launcher update.
- **Game compatibility:** A native loader candidate was compiled separately. Existing released games may require a separate game update to recognize flat-ID folders. Native track registration remains experimental.

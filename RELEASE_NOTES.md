# Crash Forge: Racing Launcher v0.3.46 - Snapshot

Small maintenance update following v0.3.45.

- Fixed Tk window positioning on secondary displays **to the left or above the primary monitor**, including negative desktop coordinates.
- Corrected positioning for the launcher window, maximize, drag, resize, compact Settings, the account dropdown and the Editor selector.
- Kept the three standalone Windows editor EXEs launching on the same display as the launcher, without command windows or requiring a separate Python installation.
- Preserved the manually selected game folder and the independent Launcher/Game NEWS and update channels.

**Launcher-only correction.** No game, ISO, mods or saved games are included. The game is released independently.
